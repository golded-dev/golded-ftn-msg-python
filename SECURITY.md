# Security

Treat message files as untrusted input. This package parses local files and writes
only to the area selected by the caller. It does not execute message content.
Callers remain responsible for choosing paths and controlling directory access.

Report suspected vulnerabilities privately to the repository maintainer through
an available private channel. Include a minimal synthetic reproducer, affected
version and expected behaviour. Never send a private message archive or secrets.

Version 1.x is the supported API line. No public hosting or publication status is
implied by this policy.
